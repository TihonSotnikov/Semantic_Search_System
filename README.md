# 🔍 Система семантического поиска по корпоративной базе знаний

## 📝 Описание проекта
Данный веб-сервис реализует технологию семантического поиска в базе данных при помощи NLP (Natural Language Processing) и векторного представления данных.

## 🚧 Проект находится в стадии разработки

## ⚙️ Стек технологий
* **Язык:** Python 3.10+
* **ML / NLP:** `sentence-transformers` (модель: `google/embeddinggemma-300m`)
* **Бэкенд:** Uvicorn + FastAPI
* **База данных:** SQLite
* **Фронтенд:** Jinja2, HTML+CSS+JavaScript

## 🚀 Установка и запуск

#### ❓ Для использования модели `google/embeddinggemma-300m` (выбрана по-умолчанию) может потребоваться авторизация в HuggingFace Hub. Следуйте инструкциям при запуске. Если такой возможности нет, можно выбрать другую модель в `load_model` (`main.py:43`).

#### ❗ Если вы поменяли модель, то необходимо удалить базу данных (`/app/data.db`). Это обусловлено несовместимостью эмбеддингов разных моделей.

### [Вариант 1] Менеджер окружений (рекомендуемый)
1. Установка `uv`: [Инструкция](https://docs.astral.sh/uv/getting-started/installation/)
2. Подключение виртуального окружения и скачивание зависимостей:
```sh
uv sync
```
3. Запуск:
```sh
cd app
# С доступом только на локальном хосте:
uv run uvicorn main:app --port 80
# Или запуск на открытом хосте (с доступом из сети):
uv run uvicorn main:app --port 80 --host 0.0.0.0
```

### [Вариант 2] Legacy (не рекомендуется)
1. Создание виртуального окружения:
```bash
python -m venv .venv
```
2. Активация окружения:
* Windows: `.venv\Scripts\activate`
* macOS/Linux: `source .venv/bin/activate`
3. Установка зависимостей:
```bash
pip install -r requirements.txt
```
4. Запуск:
```sh
cd app
# С доступом только на локальном хосте:
uvicorn main:app --port 80
# Или запуск на открытом хосте (с доступом из сети):
uvicorn main:app --port 80 --host 0.0.0.0
```

### Тестирование и использование

Подключение:
1. Веб-интерфейс: перейти по адресу `127.0.0.1` (Перед этим нужно импортировать базу запросом `/reset`)
2. Взаимодействие с API в браузере: `127.0.0.1/docs` (Swagger)
3. Либо HTTP-запрос (`curl`) на эндпоинты: \
GET `/dump` − Запросить базу знаний в json-формате \
POST `/add_document?title=<Заголовок>&text=<Текст>` − Добавить свой текст в базу \
POST `/reset` − Очистить базу и импортировать из файла data.json \
GET `/search?text=<Текст>` − Сделать поисковой запрос
